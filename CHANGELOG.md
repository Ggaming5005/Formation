# Changelog

## 0.1.0 — 2026-11-17

- Initial client renderer: size-aware rows, arcs and orbits, ground probing, flying motion, smoothing, teleport snapping and distance throttling.
- Native Studio preview plugin with selected-model preview and undoable configuration export.
- Four original block companions and a standalone example place.
- Portable layout and settings tests, with a separate Studio integration record.
